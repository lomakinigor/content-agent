# Пачка сценариев

В начале ответа кратко сообщи, что использовал skill `script-pack`.

## Когда использовать

Используй, когда нужно объединить два или больше готовых сценария в один файл для копирования, передачи или съёмки подряд. Если пользователь просит написать новые сценарии, сначала используй `scriptwriter`, затем собирай результат этим skill.

## Как работать

1. Определи сценарии из запроса, текущего диалога или явно названных файлов.
2. Не переписывай готовый текст, если пользователь просит только собрать его.
3. Создай или обнови файл `content/scripts/pachka-ГГГГ-ММ-ДД.md` по текущей дате.
4. Расположи сценарии в указанном пользователем порядке и пронумеруй с единицы.
5. Для каждого сценария сохрани название, сильный хук и текст под суфлёр.
6. Проверь, что количество разделов совпадает с количеством исходных сценариев и ни один текст не потерян.
7. Если идеи отмечаются в `knowledge/idea-bank.md`, укажи у соответствующих карточек путь к файлу пачки.
8. Дай пользователю кликабельную ссылку на готовый файл.

## Структура результата

```markdown
# Пачка сценариев - <дата>

## 1. <Название>

**Хук:** <хук>

**Текст под суфлёр:**

<готовый текст>
```

Повтори блок для всех сценариев без дополнительных пояснений между ними.

## Правила

- Не придумывай новые факты, цифры, хуки или CTA при простой сборке.
- Не сокращай и не исправляй авторский текст без просьбы пользователя.
- Не меняй порядок сценариев.
- Не добавляй в файл технические комментарии, отчёт о работе или ссылки на внутренние файлы.
- Используй короткое тире `-`, а не длинное.
- Если исходный сценарий отсутствует, спроси, откуда его взять, вместо выдумывания.

## Формат ответа

Коротко сообщи, сколько сценариев собрано, и дай ссылку на `content/scripts/pachka-ГГГГ-ММ-ДД.md`.
