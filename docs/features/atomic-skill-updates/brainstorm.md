# Brainstorm: atomic skill updates

1. **Проблема пользователя.** Ученик должен обновлять навыки одной командой и понимать, какая ревизия установлена.
2. **Текущее поведение.** `obnovit-agenta.sh` ожидает manifest и все навыки в `.claude/skills`, но публичный склад хранит большинство в `skills/` и не содержит manifest.
3. **Желаемое поведение.** Скрипт проверяет склад целиком до копирования, ставит выбранные навыки из `skills/` в обе папки и записывает SHA склада.
4. **Ограничения.** Нельзя изменять `USER.md`, `MEMORY.md`, `SOUL.md`, `memory/`, `knowledge/` или `content/`; пользовательские навыки вне manifest не удаляются.
5. **Альтернативы.** Дублировать все навыки в `.claude/skills` или менять updater. Выбран один канонический каталог `skills/`, чтобы не поддерживать две копии на складе.
6. **Риски.** Неполный склад и ошибка сети. Скрипт должен завершиться до копирования, если не прошли проверки; SHA записывается только после успеха.
